이조 영업관리

Windows용 영업·생산 관리 데스크톱 프로그램

이조 영업관리는 원단 영업·생산 업무를 한 곳에서 관리하는 Windows 프로그램입니다. 모든 업무 데이터는 사용자의 PC에 저장되며, 별도의 서버나 회원 가입이 필요 없습니다.

주요 기능

  • 공고 일정·체크리스트·대시보드
  • 생산 관리, 작업의뢰서, 외주작업의뢰서
  • 거래명세서 작성·인쇄·PDF/엑셀 저장
  • 매출 관리, 단가 관리 (단가 계산)
  • 거래처 정보 관리
  • 연결된 엑셀 파일: 단가·매출 엑셀 파일이 바뀌면 자동으로 다시 불러오기

구글 계정 연결 (선택 기능)

사용자가 원하면 프로그램 안에서 구글 계정으로 로그인해, 구글 드라이브에 있는 엑셀(.xlsx) 파일이나 구글 시트를 단가·매출 관리에 연결할 수 있습니다. 이때 프로그램은 읽기 전용 권한(Google Drive 읽기)만 사용하며, 사용자가 직접 고른 파일의 내용을 읽어 PC 안의 데이터로 다시 불러오는 데에만 씁니다. 구글 드라이브의 파일을 바꾸거나 지우지 않습니다. 자세한 내용은 개인정보처리방침을 확인하세요.
