개인정보처리방침

시행일: 2026년 10월 28일

이 방침은 Windows 프로그램 「이조 영업관리」(이하 “프로그램”)가 사용자의 정보와 구글 사용자 데이터를 어떻게 다루는지 설명합니다.

1. 업무 데이터는 사용자의 PC에만 저장됩니다

  • 프로그램에 입력하거나 불러온 모든 업무 데이터(공고, 생산, 거래명세서, 매출, 단가, 거래처 등)와 자동 백업은 사용자의 PC에만 저장됩니다.
  • 개발자는 이 데이터를 받거나 볼 수 없으며, 프로그램은 이 데이터를 개발자나 다른 서버로 보내지 않습니다.

2. 구글 계정 연결 (선택 기능)에서 접근하는 구글 사용자 데이터

  • 요청하는 권한: openid, email, https://www.googleapis.com/auth/drive.readonly (구글 드라이브 읽기 전용).
  • 접근하는 데이터
    • 구글 계정 이메일 주소: 프로그램 설정 화면에 “로그인됨: (이메일)”로 표시하는 데에만 씁니다.
    • 구글 드라이브 파일 목록(이름, 종류, 수정한 시각, 크기): 사용자가 파일을 고를 수 있도록 선택 창에 보여 주는 데에만 씁니다. 엑셀(.xlsx) 파일, 구글 시트, 폴더만 표시합니다.
    • 사용자가 직접 선택한 엑셀 파일·구글 시트의 내용과 정보(수정한 시각, 버전, 체크섬): 파일이 바뀌었는지 확인하고, 그 내용을 단가 관리·매출 관리로 다시 불러오는 데에만 씁니다.
  • 사용 방법: 파일 내용은 사용자의 PC에서만 처리되어 PC 안의 프로그램 데이터로 저장됩니다. 프로그램은 구글 드라이브의 파일을 만들거나, 바꾸거나, 지우거나, 공유하지 않습니다.
  • 저장: 액세스 토큰은 프로그램이 켜져 있는 동안 메모리에만 둡니다. 리프레시 토큰과 사용자가 입력한 OAuth Client Secret은 Windows의 암호화 기능으로 암호화해 사용자의 PC에만 저장합니다. 이 정보는 프로그램의 백업 파일에도 넣지 않습니다. 백업에는 연결한 파일의 ID와 이름만 들어갑니다.
  • 전송: 로그인 정보와 구글 데이터는 구글 서버(accounts.google.com, oauth2.googleapis.com, www.googleapis.com) 외의 어떤 서버로도 보내지 않습니다.

3. 수집·공유·판매하지 않습니다

  • 개발자는 어떤 개인정보나 구글 사용자 데이터도 수집하지 않습니다.
  • 구글 사용자 데이터를 개발자나 제3자에게 전송·공유·판매하지 않으며, 광고·신용 평가·대출 심사 등의 목적으로 쓰지 않습니다.
  • 사람이 구글 사용자 데이터를 읽는 일은 없습니다.
  • 광고, 분석(애널리틱스), 사용 통계, 오류 수집 도구를 쓰지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

이조 영업관리가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 것은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
이조 영업관리’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 권한 취소와 데이터 삭제

  • 프로그램에서: 설정 › 구글 계정 연결 › 로그아웃을 누르면 구글에 권한 취소를 요청하고 PC에 저장된 로그인 정보를 지웁니다. 클라이언트 지우기를 누르면 저장된 Client ID·Client Secret도 지웁니다.
  • 구글 계정에서: https://myaccount.google.com/permissions 에서 “이조 영업관리”의 접근 권한을 언제든지 삭제할 수 있습니다.
  • 구글 드라이브에서 불러와 PC에 저장된 데이터는 프로그램에서 직접 지우거나, 프로그램을 제거하고 데이터 폴더를 지우면 삭제됩니다.
