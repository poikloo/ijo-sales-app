# 구글 계정 연결 사용 방법 (구글 드라이브 파일 바로 연결)

이조 영업관리의 **단가 관리 · 매출 관리 › 연결된 엑셀 파일**에서 구글 드라이브의 엑셀(.xlsx)이나 구글 시트를 바로 연결하려면, 구글 클라우드 콘솔에서 **내 전용 OAuth 클라이언트**를 한 번 만들어야 합니다. (구글 드라이브 데스크톱 앱은 필요 없습니다.)

- 비용: 없음 (무료). 결제 정보도 필요 없습니다.
- 앱은 **읽기 전용 권한**(drive.readonly)만 받습니다. 드라이브 파일을 바꾸거나 지우지 않습니다.
- Client ID · Client Secret은 **다른 사람에게 보내거나 인터넷에 올리지 마세요.**
- 화면 메뉴 이름은 2026년 기준이며, 콘솔을 한국어로 보면 괄호 안 이름으로 보일 수 있습니다.

## 1. 프로젝트 만들기
1. <https://console.cloud.google.com> 에 회사에서 쓰는 Gmail 계정으로 로그인합니다.
2. 화면 위쪽 프로젝트 선택 상자 → **새 프로젝트(New Project)**.
3. 프로젝트 이름 예: `ijo-sales` → **만들기(Create)**. 만들어지면 그 프로젝트가 선택되어 있는지 확인합니다.

## 2. Google Drive API 사용 설정
1. 왼쪽 메뉴 ☰ → **API 및 서비스(APIs & Services) › 라이브러리(Library)**.
2. `Google Drive API` 검색 → 클릭 → **사용(Enable)**.

## 3. OAuth 동의 화면 (Google 인증 플랫폼 / Google Auth Platform)
1. 왼쪽 메뉴 ☰ → **Google 인증 플랫폼(Google Auth Platform) › 브랜딩(Branding)**.
   "아직 구성되지 않았습니다(not configured yet)"가 보이면 **시작하기(Get Started)**.
2. **앱 정보**: 앱 이름 `이조 영업관리`, 사용자 지원 이메일은 내 Gmail → **다음**.
3. **대상(Audience)**: **외부(External)** 선택 → **다음**. (개인 Gmail은 외부만 고를 수 있습니다. "외부"라도 공개되는 것이 아닙니다.)
4. **연락처 정보**: 내 Gmail → **다음**.
5. 정책 동의에 체크 → **계속** → **만들기(Create)**.
6. 왼쪽 **대상(Audience)** → **테스트 사용자(Test users)** → **사용자 추가(Add users)** → 내 Gmail 입력 → **저장**.
   (로그인할 다른 직원 계정이 있으면 함께 추가합니다.)

## 4. ⚠️ 앱 게시 (꼭 하세요: 안 하면 7일마다 다시 로그인)
앱이 **테스트(Testing)** 상태이면 구글이 로그인 정보를 **7일 뒤에 만료**시켜서, 일주일마다 앱에 "다시 로그인 필요"가 뜹니다.

1. **Google 인증 플랫폼 › 대상(Audience)** → 게시 상태(Publishing status) 아래 **앱 게시(Publish app)** → **확인**.
2. 상태가 **프로덕션 단계(In production)** 로 바뀌면 됩니다.
3. "인증(verification)이 필요하다"는 안내가 나와도 **혼자(또는 직원 몇 명) 쓰는 용도라면 신청하지 않아도 됩니다.**
4. 이미 테스트 상태에서 로그인했다면, 게시 후 앱에서 **로그아웃 → 다시 로그인**을 한 번 해 주세요. (테스트 상태에서 받은 로그인은 7일 제한이 그대로 남습니다.)

## 5. OAuth 클라이언트 만들기 (데스크톱 앱)
1. **Google 인증 플랫폼 › 클라이언트(Clients)** → **클라이언트 만들기(Create Client)**.
   (예전 메뉴: API 및 서비스 › 사용자 인증 정보 › 사용자 인증 정보 만들기 › OAuth 클라이언트 ID)
2. **애플리케이션 유형(Application type)**: **데스크톱 앱(Desktop app)**.
3. 이름 예: `이조 영업관리 PC` → **만들기(Create)**.
4. 뜨는 창에서 **클라이언트 ID(Client ID)** 와 **클라이언트 보안 비밀번호(Client Secret)** 를 복사합니다.
   - 이 창을 닫으면 Secret을 다시 볼 수 없을 수 있습니다. **JSON 다운로드**를 눌러 USB 등 안전한 곳에 보관해 두면 편합니다. (프로그램 폴더나 공유 폴더에는 두지 마세요.)
   - 잃어버렸으면 같은 클라이언트에서 Secret을 새로 추가하거나, 클라이언트를 새로 만들면 됩니다.
   - Client ID는 `….apps.googleusercontent.com` 으로 끝납니다.

## 6. 앱에 붙여 넣고 로그인
1. 이조 영업관리 → **설정 › 구글 계정 연결**.
2. **Client ID**, **Client Secret**을 붙여 넣고 **저장**.
3. **로그인** → 기본 브라우저에 구글 로그인 화면이 열립니다. (5분 안에 마쳐 주세요.)
4. 계정을 고르면 **"Google에서 확인하지 않은 앱"** 경고가 나옵니다. 내가 만든 앱이라 정상입니다.
   → 왼쪽 아래 **고급(Advanced)** → **이조 영업관리(으)로 이동(안전하지 않음)** 클릭.
5. 권한(구글 드라이브 파일 보기)을 확인하고 **계속(Continue)** / **허용**.
6. 브라우저에 **"로그인 완료, 창을 닫아도 됩니다"** 가 보이면 브라우저 탭을 닫습니다. 앱 설정에 `로그인됨 내이메일@gmail.com` 이 표시됩니다.

## 7. 파일 연결
1. **단가 관리 › 설정 탭** 또는 **매출 관리 › 매출 목록**의 **연결된 엑셀 파일** 칸 → **구글 드라이브에서 선택**.
2. 최근 파일 / 내 드라이브(폴더 열기) / 공유 문서함 / 이름 검색으로 파일을 찾아 클릭 → **선택**.
3. 이후 앱을 켤 때, 메뉴를 열 때, 앱 창으로 돌아올 때(30초 간격), 켜져 있는 동안 1분마다 파일이 바뀌었는지 확인해서, 바뀌었으면 자동으로 다시 불러옵니다.
   - 엑셀에서 온 행을 앱에서 고쳐도, 다음에 파일이 바뀌면 파일 내용으로 덮어씁니다. 앱에서 직접 추가한 행은 건드리지 않습니다.

## 다른 PC에서 쓰기
- 같은 Client ID · Secret을 그 PC의 앱에도 넣고 **로그인**을 한 번 하면 됩니다. (로그인 정보는 PC마다 따로 암호화해서 저장되고, 백업 파일에는 들어가지 않습니다.)
- 백업(JSON)을 복원하면 어떤 파일을 연결했는지는 같이 옮겨집니다. 그 PC에서 로그인만 하면 바로 이어서 동작합니다.

## 이럴 때는
| 상태 표시 | 해결 |
|---|---|
| 구글 다시 로그인 필요 | 설정 › 구글 계정 연결 › **다시 로그인**. 7일마다 반복되면 4단계(앱 게시)를 확인하세요. 구글 계정 비밀번호를 바꿨거나 6개월 이상 안 썼을 때도 나올 수 있습니다. |
| 구글 로그인 필요 | 로그아웃된 상태입니다. 다시 로그인하세요. |
| 인터넷 연결 안 됨 | 데이터는 그대로입니다. 인터넷이 돌아오면 자동으로 다시 확인합니다. |
| 파일을 찾을 수 없음 | 드라이브에서 파일이 지워졌거나 휴지통에 있거나, 공유가 해제됐습니다. 다시 선택하세요. |
| 로그인 화면에 "액세스 차단됨" | 3단계 6번에서 내 Gmail을 테스트 사용자로 추가했는지, 4단계에서 앱을 게시했는지 확인하세요. |
| Client ID 또는 Secret이 맞지 않음 | 5단계 값을 다시 복사해서 **클라이언트 변경**으로 넣으세요. 유형이 "데스크톱 앱"인지도 확인하세요. |

## 연결 끊기
- 앱: 설정 › 구글 계정 연결 › **로그아웃** (구글 쪽 권한도 취소하고 이 PC의 로그인 정보를 지웁니다). **클라이언트 지우기**는 Client ID·Secret까지 지웁니다.
- 구글 계정 쪽에서 확인: <https://myaccount.google.com/permissions> 에서 "이조 영업관리" 접근 권한을 삭제할 수 있습니다.
